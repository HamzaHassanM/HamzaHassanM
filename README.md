#### 📦 [laravel-social-auto-post](https://github.com/HamzaHassanM/laravel-social-auto-post)
> **A robust Laravel package for automatic social media publishing across 8 major platforms through a single unified API.**

- 🌐 **8 Platforms Supported:** X (Twitter), Facebook, LinkedIn, Instagram, TikTok, YouTube, Pinterest, and Telegram.
- ⚡ **Unified Driver-Based API:** Write clean, consistent code to publish text, images, and videos across channels.
- 🏢 **Multi-Tenant & SaaS Ready:** Pass API credentials dynamically at runtime per tenant or user account.
- 📡 **Event-Driven Architecture:** Lifecycle events (`SocialPostPublishing`, `SocialPostPublished`, `SocialPostFailed`) for observability and auditing.
- 📖 **Dedicated Multilingual Documentation:** Full guides in 6 languages: [hamzahassanm.github.io/laravel-social-auto-post ↗](https://hamzahassanm.github.io/laravel-social-auto-post/)

```bash
composer require hamzahassanm/laravel-social-auto-post
```
